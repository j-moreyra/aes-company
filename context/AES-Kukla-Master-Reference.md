## 1. The relationship in one paragraph

**Kukla** is an Austrian family-owned manufacturer of continuous weighing and dosing
equipment for bulk materials. **AES** is a Miami-based LLC that is Kukla's **exclusive
representative for the Americas** — AES sells, quotes, coordinates, ships, and commissions
Kukla equipment for customers across North, Central, and South America. AES buys from Kukla
and resells to the end customer, marking up Kukla's euro prices into a USD client quote.
AES also resells **Ensign Equipment, Inc.** on a separate back-to-back basis. AES's value
to the customer is a single English/Spanish/Portuguese-speaking point of contact in the
Americas, direct access to Kukla's engineering team, and end-to-end project management
from requirement gathering through start-up.

| Product | Notes |

## 9. The sales process (how a deal actually runs)

```
Lead  →  Kukla quotation (EUR)  →  AES Cost Structure (CS)  →  AES client quote (USD)  →  PO
         [Kukla Offer No.]         [CS_<code>.<deal#>.xlsx]    [AES-<code>.<deal#>-a.docx]
```

### Step 1 — Kukla quotation
AES requests a quote from Kukla. Kukla returns a PDF in **euros**, with line-item positions
(Pre-Bin ~line 110, Discharging Device ~130, Weigh Feeder ~150, Control Cabinet ~170,
cable ~180, packaging ~210, freight ~220, start-up ~230), plus delivery time and Incoterms.

### Step 2 — Cost Structure (CS) — the pricing spreadsheet
*(Automated by the `cs-generator` skill.)*

1. **Create the HubSpot deal.** Defaults every run: pipeline `default` (Projects Pipeline),
   dealstage `appointmentscheduled` (Discovery), status `Active`, vendor `AES`, deal_plant
   empty; associate the contact + company.
2. **Derive the identifiers:**
   - **Deal #** = the **last five digits** of the HubSpot deal record ID
     (e.g. `62178332593` → `32593`)
   - **Company code** = the company's **AES ID** from `Company Ref Table.xlsx`
     (e.g. **National Gypsum = 260**, **Georgia Pacific = 210**)
   - **Filename** = `CS_<company code>.<deal #>.xlsx` → e.g. `CS_260.32593.xlsx`
3. **Fill the template.** Pick the template by equipment type. Components sit in **column E**;
   **column F (euro unit cost) is the only column you enter.** Everything from column G
   rightward — exchange rate, commission markups (column L = marked-up unit sale price),
   totals — is formula-driven. Never touch it.
   - Missing component in the Kukla quote → **leave column F blank** and flag it (blank = 0).
4. **Naming rules — apply in BOTH tables** (cost table ~rows 7–15 and final quote table ~rows 22–30):
   - **Weigh feeder** → append the trailing model number: `WEIGH FEEDER, Type E-K-DBW-H-400`
   - **Shipping** → append the destination: `Shipping estimate: DAP - Texas`

### Step 3 — The client quote (Word proposal)
*(Automated by the `aes-quote-generator` skill.)*

- Output: **`AES-<company code>.<deal #>-a.docx`**
- **Prices come 1:1 from the CS file's final quote table (column I = client USD).**
  Recalculate the CS first so formulas resolve.
- **Technical specs come from the Kukla PDF** — the template's spec tables carry values from a
  previous deal and must be overwritten (capacity, center distance, belt inclination, weight, volumes).
- Structure: cover · TOC · About Us · project intro + benefits · scope of supply with spec
  tables per position · FAT · mounting/service/responsibilities · commercial quotation with
  itemized pricing + terms · signature block · appendix (client references and Kukla awards).
- **Section totals must be recomputed** from the lines actually placed — the **escape chute**
  row exists in the CS but is **excluded** from the quote document's Weighing Equipment table.
- **Quotation validity: keep the template's value.** AES's client validity is deliberately
  independent of Kukla's.
- Plant address → look it up online; the template carries the company HQ, not the plant.

## 11. Glossary

| Term | Meaning |
|---|---|
| **DAP** | Delivered at Place — the usual Incoterm on AES quotes |
| **EXW / FOB** | Ex Works / Free On Board |
| **FAT** | Factory Acceptance Test — Kukla tests every system before it ships |
| **CS** | Cost Structure — AES's internal pricing spreadsheet (euro cost → USD client price) |
| **LIW** | Loss-in-Weight (feeder) |
| **DBW** | Dosierbandwaage — dosing belt scale / weigh feeder (the "DBW" in model names) |
| **DWC-7 / DWC-7C** | Kukla's dosing & weighing electronics controller |
| **OP-G** | Kukla operator panel |
| **X2X-Link** | Kukla's screened special cable, quoted per metre |
| **ASG-800** | Kukla discharging device |
| **Pre-Bin** | Upstream buffer bin, usually stainless, feeding the weigher |
| **Escape chute** | Bypass chute (often pneumatically gated) — priced in the CS but excluded from the client quote's equipment table |
| **Discharging device** | Meters material from the pre-bin into the weigh feeder |
| **Commissioning / start-up** | On-site setup, calibration, and handover — a separate priced line |
| **Seaworthy packaging** | Export crating — a separate priced line |
| **RDF** | Refuse-Derived Fuel — alternative fuel for cement kilns |
| **Gravimetric vs volumetric** | Dosing by weight vs by volume |
