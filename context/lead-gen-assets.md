## Implications for priority #1

1. **The manual motion is real and documented.** Templates, segmentation, and a discovery
   script already exist. The automation problem is distribution and follow-up discipline, not
   copywriting.
2. **Three languages are in play.** Any workflow must handle EN / ES / PT, and the LatAm
   pipeline is where the existing traction is — while priority #1 targets U.S. and Canada.
   Worth resolving that tension explicitly before building.
3. **Follow-up is where it leaks.** Four warm prospects have unsent nudges from April and May.
   An automated follow-up cadence would likely produce more than new top-of-funnel volume.
4. **HubSpot BCC logging exists but is inconsistent.** Making that automatic would start
   populating the CRM data that `connections.md` flags as missing.

The first `/level-up` question should be: of the hundreds of manual sends, which product
template and which industry produced replies? That answer decides what gets automated.
